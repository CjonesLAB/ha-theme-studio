# Theme Studio 0.9.0

Theme Studio 0.9.0 returns dashboard styling to its original goal: a visual, no-code workflow that works predictably with Home Assistant's own dashboard tools. The editor has been redesigned around direct preview interaction and a mobile-first workflow, while existing designs and legacy CSS data remain protected.

## Highlights

- Redesigned the fine-tuning workflow around an interactive dashboard preview.
- Added three no-code card styles: **Standard**, **Liquid Glass**, and **Tech Frame**.
- Added contextual controls for colors, cards, navigation, backgrounds, and effects.
- Kept the preview visible during mobile editing and made **Apply design** save the selected profile before activation.
- Improved overlays and dialogs so card transparency stays available on dashboards without making popups unreadable.
- Improved visual feedback when a profile must be selected before applying or updating a design.
- Added runtime compatibility checks and refined effect cleanup across dashboard changes.
- Updated the complete user guide in German, English, French, and Spanish, including downloadable PDFs.

## Mobile-first, with clear boundaries

The regular visual design workflow is available on smartphones. The mobile interface intentionally hides profile duplication, JSON import/export, and the legacy CSS panel to keep editing focused and touch-friendly. These functions remain available on desktop.

Theme Studio changes the visual design only. Card order and layout continue to use Home Assistant's native dashboard editor. This avoids device-specific pixel positioning and keeps dashboards portable between desktop, tablet, and phone.

## Legacy CSS compatibility

Version 0.9.0 does not create new CSS rules, duplicates, or card positions. The legacy CSS section appears only when the selected profile already contains custom CSS or visual rules from an older release. Existing data is retained and can be maintained or removed explicitly; it is never silently deleted.

## Important notes

- Theme Studio is still an experimental community integration. Create a full Home Assistant backup before updating.
- Card effects and legacy CSS depend on the standard Lovelace card structure. Fully custom dashboards and custom panels are not guaranteed to support them.
- After updating, restart Home Assistant and reload the browser or Companion App so the new frontend files replace cached versions.

## Installation

Install or update Theme Studio through HACS, or replace the complete `custom_components/theme_studio` directory during a manual installation. Do not mix files from different versions.
