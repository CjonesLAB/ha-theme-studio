# Theme Studio 0.10.3 – Stability & Maintenance Update

Theme Studio 0.10.3 strengthens the foundation of the integration and makes
future releases safer without changing the familiar design workflow.

## Improved

- Refined the internal frontend and design architecture for easier maintenance.
- Added stricter validation for shared design profiles and release metadata.
- Expanded automated coverage for Home Assistant compatibility, frontend
  behavior, branding, and version consistency.
- Updated the main product screenshot and all current user guides for 0.10.3.
- Improved HACS presentation with corrected branding and direct installation
  links following Theme Studio's addition to the default HACS catalog.

## Compatibility

- Existing profiles, textures, backgrounds, card styles, effects, and
  per-design clock settings remain compatible.
- Theme Studio continues to require Home Assistant 2026.7.0 or newer.

## Installation

Update through HACS, restart Home Assistant, and refresh the browser with
`Ctrl + F5` or fully restart the Companion App so the 0.10.3 frontend files
replace the cached 0.10.2 files.
