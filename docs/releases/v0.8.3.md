# Theme Studio 0.8.3

Version 0.8.3 is a compatibility-focused transition release.

The experimental free-positioning feature worked differently across desktop, tablet, and mobile layouts. This release removes that unreliable editing path and returns card placement to Home Assistant's native dashboard tools. Theme Studio remains focused on visual design instead of replacing Home Assistant's layout system.

## What changed

- Removed the experimental dashboard card movement mode from desktop and mobile.
- Removed the direct card editor entry points from the dashboard and Theme Studio.
- Removed the controls for creating new horizontal and vertical card offsets.
- Returned dashboard layout and card placement to Home Assistant's native editing tools.

## Existing rules remain safe

Existing visual rules and their styling values are preserved. Legacy horizontal and vertical offsets also remain active after the update so that an existing dashboard does not change unexpectedly.

Theme Studio shows a notice when legacy position values are present. The new **Disable all position adjustments** action clears only the horizontal and vertical offsets. Width, height, spacing, opacity, font size, rounded corners, selectors, and all other rule values remain untouched.

Duplicating an old rule does not copy its legacy position offsets.

## After updating

No existing design profile or visual rule is deleted during the update. If an older dashboard still contains unwanted X/Y offsets, open the expert section and select **Disable all position adjustments**. Review the dashboard before confirming; only the legacy position values are removed.

As with every early Theme Studio release, creating a Home Assistant backup before updating is recommended. Reload the browser or Companion App after the update so that the 0.8.3 frontend files replace cached files from 0.8.2.

The README and all four user guides now describe the transition and use an updated 0.8.3 overview image.

## Next step

Version 0.9.0 will redesign dashboard customization around a no-code workflow and Home Assistant's native layout rules. The goal is predictable behavior across desktop, tablet, and mobile without recreating Home Assistant's dashboard editor.
