# Theme Studio 0.10.5

Theme Studio 0.10.5 is a maintenance and privacy release focused on dependable previews, protected overlay content, and a cleaner foundation for future development.

## Highlights

- overlay dialogs now use a fully opaque Theme Studio material, preventing dashboard content from showing through
- Liquid Glass overlays add strong background blur while retaining selected card textures and background images
- the real-dashboard device preview performs less repeated work and cleans up its temporary state reliably
- large preview and theme-generation modules are split into focused, maintainable components
- automated checks now cover more frontend behavior, lifecycle handling, code quality, and supported Home Assistant versions
- the main screenshot and all four downloadable user guides are updated for version 0.10.5

## Update

Update Theme Studio through HACS and restart Home Assistant. If an older frontend is still visible, refresh the browser without using its cached files.
