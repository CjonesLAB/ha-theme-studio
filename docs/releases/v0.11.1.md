# Theme Studio 0.11.1

Theme Studio 0.11.1 makes timed cover control safer and keeps estimated cover positions synchronized across dashboards.

## Highlights

- shared backend position estimates keep phone, tablet, and desktop cards aligned for covers without native position feedback
- timed cover movements and safety stops continue in Home Assistant after the dashboard or editor is closed
- protected opening and closing learning rides measure travel time and include a permanent emergency stop plus a 60-second safety timeout
- defensive handling for direction changes, reconnects, Home Assistant restarts, delayed device responses, failed stop commands, and interrupted learning rides
- restored fallback synchronization for older or temporarily unavailable live-position subscriptions, with retry throttling instead of request loops
- localized controls, status messages, errors, and learning-ride guidance in German, English, French, and Spanish
- refreshed overview, compact cover, cover-editor, and cover-detail screenshots plus updated downloadable guides in all four documentation languages

## Safety note

For covers without native position feedback, the displayed percentage remains an estimate. Physical end stops and the device itself remain authoritative. Timed control requires a native stop command, entered travel times, and a confirmed passive actuator check. The passive check observes Home Assistant states only and sends no movement command.

## Update

Update Theme Studio through HACS and restart Home Assistant. Refresh the browser or Companion App without cached files if the previous frontend remains visible.
