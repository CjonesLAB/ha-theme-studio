# Theme Studio 0.10.1

Theme Studio 0.10.1 completes the Community Gallery experience introduced with
the 0.10.0 material-design milestone.

## Fixed

- Dashboard textures from shared 0.10.x designs now appear in Theme Studio's
  built-in Community Gallery preview.
- Global card textures and their darkening level are now represented in those
  previews as well.
- Gallery texture paths are strictly validated and mapped to bundled local
  Theme Studio assets. Remote and embedded image sources remain blocked.

## Installation

Update through HACS, restart Home Assistant, and refresh the browser with
`Ctrl + F5` or fully restart the Companion App. In Theme Studio, use
**Aktualisieren** once to refresh the Community Gallery.
