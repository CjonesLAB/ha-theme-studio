# Theme Studio 0.10.2

Theme Studio 0.10.2 makes clock presentation part of the design instead of a
shared dashboard setting.

## Security and permissions

- Theme Studio is now available only to Home Assistant administrators.
- Every WebSocket command that writes the generated theme file or reloads
  Home Assistant themes enforces administrator access before making changes.
- Stored settings, profiles, active designs, and recovery points remain
  separated for each administrator account.

## Improved

- The analog or digital style of Home Assistant's built-in Clock card is now
  stored with the active Theme Studio design.
- Switching between saved designs immediately restores their individual clock
  styles.
- Native clock options such as the face style, date, seconds, and card size
  remain untouched.
- Theme Studio's own Clock card continues to follow the same design setting.
- Tech Frame state effects now keep their complete outline inset inside the
  card, including large history and graph cards.

## First use

Apply a saved design, edit the Home Assistant Clock card, choose **Analog** or
**Digital**, and save the card once. Repeat this once for each design that
should use a different clock style. Later design changes restore the stored
choice automatically.

## Installation

Update through HACS, restart Home Assistant, and refresh the browser with
`Ctrl + F5` or fully restart the Companion App so the 0.10.2 frontend files
replace the cached 0.10.1 files.
