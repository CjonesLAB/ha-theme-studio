# Theme Studio 0.8.2

Theme Studio 0.8.2 expands Expert CSS into a practical visual toolkit for individual Lovelace cards. It adds a searchable CSS example library, direct card positioning, responsive per-device rules, and a mobile-first movement mode while keeping every user’s customizations separate.

> **Experimental feature notice:** Expert CSS, the CSS library, and the direct card editor are experimental. They modify Lovelace presentation and may need adjustment after Home Assistant updates. Create a backup and test changes carefully. On smartphones, direct card editing intentionally supports moving cards only. Use desktop or tablet for size, spacing, column span, opacity, typography, rounded corners, multiple selection, and reset.

## Highlights

- Searchable library with 32 ready-to-use CSS examples, categories, previews, and safe insertion into the Expert CSS editor.
- Direct card selection on standard Lovelace dashboards using stable per-card keys.
- Live positioning with drag controls, direction buttons, placement guides, and per-card reset.
- `Ctrl`/`Cmd` multiple selection on desktop and tablet.
- Separate responsive rules for desktop, tablet, and smartphone.
- Mobile card mode in the dashboard menu with one-finger movement and automatic position saving.
- Improved mobile placement so a saved position remains consistent after card mode is closed.
- Theme Studio controls stay hidden outside compatible dashboards and while Home Assistant’s native dashboard editor is active.
- Expert CSS settings, card rules, and designs remain private to each Home Assistant user.
- Updated English, German, French, and Spanish user guides, including downloadable PDFs.

## Compatibility and limitations

- Card effects, Expert CSS, and direct card editing require the standard Lovelace card and layout structure.
- Fully custom dashboards and custom panels that render their own HTML or web components are not supported by these features.
- Smartphone card mode is limited to moving cards. The full editor is available on desktop and tablet.
- Portable design JSON exports intentionally exclude Expert CSS, local entity assignments, dashboard effects, and local background-image paths.

## Updating

Install the update through HACS or replace the complete `custom_components/theme_studio` directory, restart Home Assistant, and refresh the frontend. In the Companion app, close and reopen the app completely after the restart.
