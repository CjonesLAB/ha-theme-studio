# Theme Studio 0.10.0

Theme Studio 0.10.0 is a visual milestone. Dashboards can now share one coherent material language or give selected cards their own identity—all through the Home Assistant interface and without custom CSS.

![Theme Studio 0.10.0 overview](../images/v010/theme-studio-overview.webp)

## Highlights

### 40 dashboard-ready surfaces

The new Texture Gallery includes four curated collections: **Carbon**, **Metal**, **Wood**, and **Abstract**. Each collection contains ten high-resolution surfaces designed to remain sharp on large dashboards.

Use a surface as the full dashboard background, apply it globally to cards, or select it only for an individual card. Separate opacity and darkening controls help keep dashboard content readable.

### Global design or individual cards

Global card styling now provides a fast way to give the whole dashboard one consistent surface. When one card needs a different treatment, **Theme Studio Design** is available directly in Home Assistant's native card editor.

An individual card can choose its own Standard, Liquid Glass, or Tech Frame style, background color, bundled texture, custom image, opacity, and related colors. Local choices stay with that card; every card without an override continues to follow the global design.

### Analog and digital clock card

The new **Theme Studio Clock** is a real dashboard card. Add it from Home Assistant's normal card picker, choose an analog or digital face, and position it with the same dashboard layout tools used for other cards.

### More polished interaction

- Texture selection uses a clear preview and explicit **Apply** action.
- Card choices show hover and active states before applying.
- Save actions provide visible pending and success feedback.
- Saving a per-card design applies it immediately and closes the editor.
- Home Assistant's native pickers and dialogs remain visually independent from dashboard styling.
- Camera and picture cards respect the selected card geometry consistently.
- Status, energy, climate, and alert frames are capped at 2 px and drawn inside card boundaries.

## Important notes

- Create a full Home Assistant backup before updating.
- Restart Home Assistant after installation, then refresh the browser with `Ctrl + F5` or fully restart the Companion App.
- Existing profiles remain available. Cards without an individual design continue to use the global Theme Studio settings.
- Card effects depend on the standard Lovelace card structure. Fully custom dashboards or cards that render an unrelated internal structure may not support every effect.

## Installation

Install or update Theme Studio through HACS, or replace the complete `custom_components/theme_studio` directory during a manual installation. Do not mix files from different versions.
