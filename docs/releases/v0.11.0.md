# Theme Studio 0.11.0

Theme Studio 0.11.0 adds compact native dashboard cards for lights, energy-aware smart plugs, and covers while keeping the active Theme Studio design in control of their appearance.

## Highlights

- new light card with brightness control, a full color wheel, native Kelvin handling, and direct W, RGBW, or RGBWW white-channel control according to the entity capabilities
- interlocked color and white controls prevent RGB channels from being used when a dedicated white channel is selected
- new smart-plug card with live power, energy totals, a compact activity graph, and automatic matching of related electrical sensors
- new universal cover card with open, stop, close, animated position feedback, optional naming, appearance choices, and guided travel-time calibration
- card dimensions remain editable through Home Assistant's native layout controls
- complete frontend localization for German, English, French, and Spanish, split into maintainable language files
- updated screenshots and downloadable user guides for all supported documentation languages

## Update

Update Theme Studio through HACS and restart Home Assistant. Refresh the browser or Companion App without using cached files if the previous frontend remains visible.
